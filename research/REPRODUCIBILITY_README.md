# Reproducibility boundary

## Purpose

This file states exactly what the committed executable suite regenerates and what remains a recorded research result.

The suite is hermetic for the finite fixture verifier and collision/mutation campaigns. It does not freshly rerun every historical resolver issue and does not require package indexes or network access.

## Current executable claims

The committed runner computes, rather than hard-coding, the following:

- finite trace-only verifier checks;
- exactly 250 distinct structural mutation cases;
- the extended 256-world projection search;
- executable subset-minimality checks in the committed fixture;
- hermetic verifier replay.

The 18-case corpus replay and its 18/18 round-trip/isolation figures are committed research fixture results. They are not fresh resolver executions of all 18 historical cases.

## Environment

- Python: 3.13.x or compatible Python 3 runtime supported by the research harness.
- External Python packages: none required for the hermetic research suite.
- Network: not required.
- Package indexes: not required.
- Native resolver packages: not required.
- Historical source/issue analysis: recorded in the research documents; not regenerated by the runner.

## Command

From repository root:

```bash
python research/run_reproducibility.py
```

The runner imports only the committed research harnesses and generates its own mutation/search counts.

## Interpretation

A PASS from the executable suite establishes reproducibility of the implemented finite research harnesses.

It does not, by itself, freshly reproduce:
- public historical issue executions;
- Poetry/pipgrip runtime executions;
- upstream resolver internals at current versions;
- ecosystem-wide portability;
- maintainer validation.

Those remain explicitly documented evidence classes.


## Test entry point

The repository also contains an explicit standard-library test module:

```bash
python -m unittest research.test_reproducibility
```

This covers SAT/UNSAT reconstruction, subset-minimality, serialization, structural integrity, coverage, proof claims, provenance, activation, artifact feasibility, branch scope, the 250-case campaign, and the 256-world projection search.

For machine-readable output from the aggregate runner:

```bash
python research/run_reproducibility.py --json
```
